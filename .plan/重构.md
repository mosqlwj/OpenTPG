## 3. ATPG 算法设计

### 3.1 共享算法组件

**文件位置**: `opentpg/src/algorithm/shared/`

| 组件 | 功能 |
|------|------|
| DAlgorithm | D 算法路径敏化 |
| Backtracker | 回溯引擎 |
| ImplicationEngine | 前向/反向蕴涵 |
| SPLITModel | 9 值逻辑模型（良机/坏机分离） |
| SCOAP | 可控性/可观测性度量 |
| XPathChecker | X 路径检查器 |

### 3.2 PODEM 算法

**文件位置**: `opentpg/src/algorithm/podem/PODEM.h`

核心流程：
1. ComputeObjective() - 计算目标
2. Backtrace() - 回溯算法
3. MakeDecision() - 执行决策
4. CheckImplication() - 蕴涵检查
5. PropagateD() - D 传播

### 3.3 FAN 算法

**文件位置**: `opentpg/src/algorithm/fan/FAN.h`

核心特性：
- Headline 计算
- 多重回溯
- 动态唯一性检查

### 3.4 SOCRATES 算法

**文件位置**: `opentpg/src/algorithm/socrates/SOCRATES.h`

核心特性：
- 学习系统（Learning）
- 唯一敏化
- SCOAP 度量驱动的决策

## 5. 数据模型重构

### 5.1 内存管理优化

| 现有问题 | 解决方案 |
|---------|---------|
| 裸指针使用 | 使用 `std::shared_ptr`, `std::unique_ptr` |
| 手动内存管理 | RAII + 对象池 |
| 内存泄漏风险 | 智能指针自动释放 |

### 5.2 GPU 友好数据布局

每个数据模型添加 `GPULayout` 结构：
- 扁平化数组
- 连续内存
- 易于 GPU 访问

### 5.3 关键数据模型重构

| 组件 | 现有位置 | 新位置 | 主要改动 |
|------|---------|-------|---------|
| Gate | flowtpg/model/Gate.h | model/netlist/Gate.h | shared_ptr + GPULayout |
| Netlist | flowtpg/model/Netlist.h | model/netlist/Netlist.h | shared_ptr + GPU 布局 |
| Fault | flowtpg/model/Fault.h | model/fault/Fault.h | 智能指针 |
| TestCube | flowtpg/model/TestCube.h | model/pattern/TestCube.h | 优化内存布局 |
