# Code Style

* `文件命名`：文件名与该文件中的核心类同名（包括大小写），如果文件中并没有核心类，那么该文件应该采用小写字母
* `类的命名`：类名遵循大驼峰风格
* `函数命名`：函数名遵循大驼峰风格
* `枚举命名`：枚举类型名遵循大驼峰风格，枚举项命名规则为全大写、下划线分隔字段
* `变量命名`：成员变量、局部变量采用小驼峰风格
* `注释`：避免对代码逻辑使用行注释（`// xxxx`），避免使用 `/* xxx */` 注释
* `段落`：逻辑段落之间应该流出空行
* `include顺序`：include 文件要分组，各组之间排列顺序应该遵循稳定性由低到高排列，比如，本项目自研在前、开源软件在中、标准库在后
* `基础类命名`：具备高通用性的纯数据结构、纯算法的模板、类、函数等，命名采用C++库的命名风格，原因是，这些类一般与C++标准库有替代关系。
* `目录、模块及名字空间`：在 src 目录下的子目录，一个目录就对应一个模块、一个模块有自己独立的名字空间
* `特殊目录命名`：下面这些不应该作为模块命名：include、src、test、doc
* `特殊名称后缀`：实现（impl）、缺省（default）
* `代码格式化`：代码提交之前，请使用 build.sh format 进行代码格式化
* `文件后缀`：请遵循通俗的 C/C++ 文件名后缀：.h 为头文件，.cpp 为实现，.inc 为可以被 `#include` 嵌入到代码的文件
* `C++语言标准`：c++11 为当前唯一支持的语言标准，请不要使用老的语言标准，为了编译器的兼容考虑，也禁止使用比 C++11 更新的语言标准
